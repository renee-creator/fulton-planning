# Fulton Planning Studio

Weekly curriculum planning for Fulton Community School & Farm. Educators complete the Classroom and Individual Curriculum Plans, upload paper plans to have them transcribed, follow threads across weeks, and download printable PDF or Word forms. Threads, projects, the lens, and project stories each download as a PDF and as a Word file, laid out for display with a few things that matter set large, in educators' own words. Threads, projects, and the lens each offer a Summary, which is one sheet, and a Full set, which adds a sheet for every thread, every part of a project, or every moment. A run of moments uses the whole width of the sheet, with the week beside the credit, so the narrow column is not left empty. Every sheet stands alone. A group under a heading that would fit a sheet of its own starts a fresh sheet rather than being split, a heading that does carry on is repeated with the word continued, and a page that is barely over is set a little smaller rather than spilling a few lines. A completed curriculum plan prints to the writing it holds, with no ruled lines and no blank space stretched to fill a sheet, so it holds two pages. The first sheet is the observation through the provocations, and the second is the curriculum brainstorm, the web, and the languages, open questions and environment notes. A section left empty prints as its heading alone. Blank forms keep their rules and their room to write. These pages use the same two typefaces as the app, Bricolage Grotesque and Figtree, kept in the fonts folder under the SIL Open Font License and carried inside each PDF and Word file. A short page is set larger so it fills the sheet. No printout names the AI tool. The Lens page reads the year's plans through a lens, this year Graphic Languages, and gathers moments in educators' own words by classroom and week. The school can hold several lenses, added, duplicated and removed by the director in Program settings, and the page shows one at a time. Claude can draft a lens from its name, proposing what it means here, the questions, the languages and the words, which the director uses or discards. Check the words counts what each word of a lens would find across the saved plans and names the sections it found them in, so words that catch planning language rather than children's work can be dropped. That count is arithmetic on the school's own plans, not Claude. Each lens keeps its own readings, and a reading made before the school held more than one opens under the first lens. Every educator types their own name at the top, and a shared sign-in such as Staff is never used as an educator's name. A plan cannot be started or marked ready without one.

Notice and Wonder is the school's observational frame and sits beside the plans an educator can start. A moment is written in two boxes, what I noticed and what I wonder, and it is never filed against a week. It keeps the educator who wrote it, the day, the classroom, and optionally a project or a thread. Nothing expires and nobody approves it. Every educator sees every moment, because supporting children is school-wide. A plan for that classroom offers its moments without opening them, and one tap drops the words into the observation so nothing is written twice. Find threads and the lens read moments alongside plans, and a single moment is never enough on its own to raise a thread. A moment is never counted as a plan, so it stays out of the week packet, out of Final remarks due, and out of any plan download. Moments live on their own page, Moments in the top menu, which opens on the record rather than on a blank form. Keep a moment is there, and after keeping one an educator lands back on the record with it at the top. The same moments can be read five ways, most recent first, by classroom, by educator, by month, or by project and thread, and the way of looking is remembered. A classroom pill and a range narrow what is in view. Summary PDF prints the view to one sheet for display and Full PDF prints every moment with what the educator wondered, both with a Word copy, and the printout carries the same groups the page is showing. The director can ask Claude to read the moments in view and name up to five patterns, each a short label with the moments it draws on, and that reading stays on the page for the whole team and prints with it. Threads the team decides to follow further become projects, which belong to a classroom, can be joined by other classrooms, and can also begin school-wide.

## How it runs

- **Web page** `index.html`, published with GitHub Pages at https://renee-creator.github.io/fulton-planning/
- **Server** `server.js`, running on Render at https://fulton-planning.onrender.com. Open that address in a browser to see a status page.
- **Plans**, followed threads and projects are kept as files in the private repository `fulton-planning-records`. Every change is saved there with the educator's name, so earlier versions can always be recovered from GitHub's history.

This repository holds code only. It never holds plans, children's names, or keys.

## Server settings on Render

| Setting | What it holds |
|---|---|
| `TEACHER_PASSCODES` | Each educator's name and passcode, separated by commas, like `Maren=maple garden 42,Tobin=river stone 7`. Passcodes need at least 6 characters. Removing an educator signs them out. |
| `DIRECTOR_NAMES` | Names from `TEACHER_PASSCODES` who may change Program settings and delete plans or followed threads. Defaults to `Renee`. |
| `GITHUB_TOKEN` | A fine-grained GitHub token with Contents read and write on `fulton-planning-records` only |
| `ANTHROPIC_API_KEY` | The same key TREE uses |
| `RECORDS_REPO` | Optional. Defaults to `renee-creator/fulton-planning-records` |
| `ALLOWED_ORIGINS` | Optional. Extra websites allowed to use the server |
| `READS_PER_HOUR`, `CAREFUL_PER_HOUR` | Optional. Hourly Claude request limits, 800 and 400 by default, sized for a whole-school scan |

## Who can do what

Every educator can write, edit, upload, and download plans, add educator names, and use Claude assist. Any educator can stop following a thread, which moves it to No longer following, and anyone can follow it again. A thread followed by mistake can be undone, which puts it back among the threads Claude found as if it had never been followed. Any educator can connect a plan to a thread the school is following, or disconnect it. A connected plan shows a Following the thread note at the top, and the thread's name prints on the PDF and Word form. A plan is also connected when it was started from the thread or when the thread quotes it. Any educator can delete a plan. The page asks twice before it does, and every deletion is written to the Render log with the educator's name. Any educator can start a project from a followed thread, start a school-wide project, add threads and classrooms to a project, write its stories, and close it. A thread shows what children keep returning to. A project is the team's reading of what lies underneath. Starting one records the experience it grew from, what may lie underneath, the educators' intent, and who decided. The reading and the intent can be revised, and earlier versions are kept with their dates. A project holds possible directions as hypotheses and has no end date or steps to complete. A direction is named with a short label and its materials sit under it, and the drawing sets text smaller until it fits rather than dropping the end of a line. Claude never starts a project, adds a thread to one, or writes the team's reading of what may lie underneath. It points out a new thread that may be related. On the project page it offers the same two kinds of help a plan has. Strengthen wording rewords what educators wrote and adds nothing, and the possible directions can be drafted from what the project and its threads already say. Each suggestion is shown first and nothing changes until an educator chooses it. A followed thread can be brought into the Classroom Plan for the week. If that classroom already has a Classroom Plan for the week the thread is connected to it, and if it has none one is started with nothing written in. The curriculum web draft also reads the threads a plan follows. Only the director writes Director feedback on a plan. Educators see it read-only, are told in the sidebar when a note is waiting, and can reply under it. Everyone can open the Lens page. Only the director can run Find threads with Claude, ask Claude to read through the lens, change the lens wording in Program settings, change Program settings, remove a thread permanently, and remove a project. The server enforces this, not just the page.

## Claude assist

Drafting from notes, Strengthen wording, family updates and transcribing everyday plans use Claude Haiku. Sorting scanned pages, finding threads, reading through the lens, project stories and transcribing handwritten scans use Claude Sonnet. The lens reading is told to read for children's thinking, never to rate how a product looks, and to leave an answer empty when the plans say nothing. Every Claude request the server turns away is written to the Render log with the reason. Plans are sent to Anthropic only to answer each request, and Anthropic does not use them to train its AI.

## Editing the page

The page is built from two parts in `src`. `app.html` is Planning Studio and `shim.html` adds sign-in and the connection to the server. After changing either one, run `python3 tools/build.py` to rebuild `index.html`.

## Free plan notes

The Render server sleeps after 15 quiet minutes. The first visit after that takes about a minute while it wakes, and the page says so. Typing is gathered and saved to GitHub within about 15 seconds.
